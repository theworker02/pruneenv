# pruneenv

Prune identifiers and env tokens for idempotent workflows.

**Site:** https://theworker02.github.io/pruneenv/

## Install / run

```bash
git clone https://github.com/theworker02/pruneenv.git
cd pruneenv
node src/cli.js
node --test
```
